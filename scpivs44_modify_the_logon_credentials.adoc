= 修改登入憑證
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以修改SnapCenter Plug-in for VMware vSphere的登入憑證。

.開始之前
您必須知道SnapCenter Plug-in for VMware vSphere的 IP 位址和登入憑證。您還必須記下從維護控制台產生的 MFA 令牌。

* 部署適用SnapCenter Plug-in for VMware vSphere時顯示 IP 位址。
* 使用部署SnapCenter Plug-in for VMware vSphere期間提供的或稍後修改的登入憑證。
* 使用維護控制台系統設定選項產生一個 6 位數的 MFA 令牌。


.步驟
. 登入SnapCenter Plug-in for VMware vSphere管理 GUI。
+
使用格式 `\https://<appliance-IP-address>:8080`

. 選擇頂部工具列中的“設定”圖示。
+
image:scpivs44_image28.jpg["SnapCenter Plug-in for VMware vSphere窗口"]

. 在「*設定*」頁面的「*使用者*」部分中，選擇「*編輯*」。
. 輸入新密碼並選擇*儲存*。
+
所有服務可能需要幾分鐘才能恢復。
