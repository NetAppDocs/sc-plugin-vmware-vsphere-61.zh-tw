= 建立並匯入證書
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
SnapCenter Plug-in for VMware vSphere採用 SSL 加密來與客戶端瀏覽器進行安全通訊。雖然這確實支援透過網路傳輸加密數據，但建立新的自簽名憑證或使用您自己的憑證授權單位 (CA) 基礎架構或第三方 CA 可確保該憑證對於您的環境是唯一的。
