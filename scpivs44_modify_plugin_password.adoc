= 從維護控制台修改SnapCenter Plug-in for VMware vSphere
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
如果您不知道適用於SnapCenter Plug-in for VMware vSphere的管理員密碼，您可以從維護控制台設定新密碼。

.開始之前
在停止並重新啟動SnapCenter Plug-in for VMware vSphere之前，您應該暫停所有方案。

.關於此任務
有關存取和登入維護控制台的信息，請參閱link:scpivs44_access_the_maintenance_console.html["存取維護控制台"^]。

.步驟
. 從 VMware vSphere 用戶端中，選擇SnapCenter Plug-in for VMware vSphere所在的虛擬機器。
. 在虛擬設備的「*摘要*」標籤中，選擇「啟動遠端控制台*」以開啟維護控制台窗口，然後登入。
+
有關存取和登入維護控制台的信息，請參閱link:scpivs44_access_the_maintenance_console.html["存取維護控制台"^]。

+
image:scpivs44_image29.jpg["維護控制台視窗"]

. 在應用程式設定中輸入“*1*”。
. 輸入“*4*”更改使用者名稱或密碼。
. 輸入新密碼。
+
SnapCenter VMware 虛擬設備服務已停止並重新啟動。
