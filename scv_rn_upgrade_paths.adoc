= 升級路徑
:allow-uri-read: 


[role="lead"]
您可以升級到的適用SnapCenter Plug-in for VMware vSphere版本取決於您目前正在執行的版本。

[NOTE]
====
僅 VMware vCenter Server 7 Update 1 及更高版本支援升級至SnapCenter Plug-in for VMware vSphere。對於版本 7 更新 1 之前的 VMware vCenter 伺服器，您應該繼續使用 SCV 4.7。

====

|===
| 如果您使用的是 SCV 版本… | 您可以直接將 SCV 升級到...

 a|

 a|

 a| 
SCV 4.8
 a| 
SCV 4.9 和 SCV 5.0



 a| 
SCV 4.7
 a| 
SCV 4.8 和 SCV 4.9

|===
